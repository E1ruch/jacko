# Roadmap Jacko

Сначала завершаем серверный MVP и проверяем сквозные сценарии через API. Затем проектируем веб-клиент. После каждого этапа обновляем статус и фиксируем результат проверки.

| Этап | Статус | Критерий готовности |
|---|---|---|
| Запись сообщений, история и WebSocket | Готово | PostgreSQL хранит сообщения и журнал. Два шлюза доставляют события, при переподключении восстанавливают пропуски по курсору. |
| Учётные записи и сессии | Готово для стенда | Регистрация, вход, ротация и отзыв работают через HTTP. Публичный запуск требует подтверждения email, сброса пароля и лимитов. |
| Сообщества, каналы и приглашения | Готово | Два пользователя проходят от регистрации и приглашения до двусторонней переписки без ручных действий в БД. |
| Ответы, правки и удаления | Готово | Проверены ответы в том же канале, права автора, повторные запросы и восстановление правок и удалений через два шлюза. Удалённый текст исключён из истории и журнала доставки. |
| Изображения и вложения | Далее | Загрузка в S3-совместимое хранилище, проверка размера и типа, привязка к сообщению и выдача по правам канала. |
| Онлайн-статусы и участники | Запланировано | Список участников с пагинацией и онлайн-статусом, который обновляется и истекает после отключения. |
| Безопасность и модерация для беты | Запланировано | Подтверждение email, сброс пароля, лимиты запросов, жалобы и базовые действия модерации. |
| Приёмка бэкенда | Запланировано | OpenAPI описывает REST MVP. Пройдены сценарии отказов и восстановления из резервной копии, измерена нагрузка на стенде. |
| Веб-клиент | После приёмки бэкенда | Два браузера обмениваются сообщениями. Измерены локальный отклик, отрисовка и плавность прокрутки. |
| Tauri и функции после MVP | После веб-клиента | Проверены сборки Windows и macOS. Голос, ЛС, реакции и поиск планируются отдельно. |

Локальная проверка доставки до WebSocket ранее дала p99 54–59 мс при 32 клиентах, 8 отправителях и 6 400 доставках за прогон. Проверка цели в 10 000 соединений на узел впереди.

**11 ноября 2026.** Миграция 000007 применена на локальном стенде с сохранением существующих сообщений. Проверки с PostgreSQL и Redis в Docker, `go test -race` и `go vet` прошли. Ближайший этап — API изображений и вложений.
