# Roadmap Jacko

Сначала завершаем серверный MVP и проверяем сквозные сценарии через API. Затем проектируем веб-клиент. После каждого этапа обновляем статус и фиксируем результат проверки.

| Этап | Статус | Критерий готовности |
|---|---|---|
| Запись сообщений, история и WebSocket | Готово | PostgreSQL хранит сообщения и журнал. Два шлюза доставляют события, при переподключении восстанавливают пропуски по курсору. |
| Учётные записи и сессии | Готово для стенда | Регистрация, вход, ротация, подтверждение email и восстановление пароля работают через HTTP. |
| Сообщества, каналы и приглашения | Готово | Два пользователя проходят от регистрации и приглашения до двусторонней переписки без ручных действий в БД. |
| Ответы, правки и удаления | Готово | Проверены ответы в том же канале, права автора, повторные запросы и восстановление правок и удалений через два шлюза. Удалённый текст исключён из истории и журнала доставки. |
| Изображения и вложения | Готово для стенда | Подписанная загрузка JPEG/PNG, проверка содержимого, привязка к сообщению и скачивание по правам канала. Проверено с приватным S3-бакетом в Docker. Превью и автоочистка остаются перед бетой. |
| Онлайн-статусы и участники | Готово | Список участников и ролей с курсорной пагинацией. Проверены два устройства на разных шлюзах, истечение записи и работа списка при недоступности Redis. |
| Безопасность и модерация для беты | Готово для стенда | Проверены одноразовые почтовые коды, отзыв сессий после сброса, Redis-лимиты и рассмотрение жалоб владельцем. SMTP беты и лимиты на входном прокси требуют настройки перед публикацией. |
| Приёмка бэкенда | Завершена | Локальные проверки отказов Redis и S3 и восстановления данных прошли. Один шлюз удержал 10 000 подключений. p99 на этой нагрузке составил 231–445 мс. Серверные задержки отслеживаем в Prometheus. |
| Веб-клиент | Функциональные сценарии MVP проверены | Два браузера обмениваются сообщениями. Измерены локальный отклик, отрисовка и плавность прокрутки. |
| Tauri и функции после MVP | После веб-клиента | Проверены сборки Windows и macOS. Голос, ЛС, реакции и поиск планируются отдельно. |

Локальная проверка доставки до WebSocket ранее дала p99 54–59 мс при 32 клиентах, 8 отправителях и 6 400 доставках за прогон. В приёмочном прогоне один шлюз удержал 10 000 соединений и выполнил 50 000 доставок. [Протокол приёмки и замеры](backend-acceptance.md).

**11 ноября 2026.** На локальном стенде проверены вложения от загрузки в S3 до доставки по WebSocket и скачивания участником. Добавлен список участников с онлайн-статусами по WebSocket-подключениям. Проверки в Docker с `go test -race` и `go vet` прошли. Ближайший этап — безопасность и модерация для беты.

**12 ноября 2026.** Почтовые сценарии проверены через локальный Mailpit. Проверены отзыв старых токенов после сброса, права на жалобы и ответ 429 при исчерпании лимита. Следующий этап — приёмка бэкенда.

**Аудит API, 11 ноября 2026.** Обновлены Go и зависимости с исправлениями безопасности; добавлены сроки REST-операций, локальные лимиты аутентификации, предел WebSocket-соединений, readiness PostgreSQL и индекс истории без удалённых сообщений. Автоматизированы проверки сообществ и S3-вложений. Полный прогон: `./server/scripts/test-api.sh`. [Выводы и ограничения архитектуры](api-audit-2026-11-11.md).

## Веб-клиент

| Этап | Статус |
|---|---|
| Каркас и контракты | Готово. Svelte 5, TypeScript и Vite, типы из OpenAPI, прокси HTTP и WebSocket. Маршрут канала сохраняется при входе. |
| Чат между двумя сессиями | Проверено на локальном Go API. Два аккаунта прошли регистрацию, приглашение и обмен сообщениями. Проверены подгрузка истории и повтор отправки с прежним nonce после потери HTTP-ответа. |
| Восстановление и прокрутка | Готово для текстовой ленты. События применяются пачками. Лента измеряет высоты и отображает видимые строки с запасом. IndexedDB хранит историю, курсор и позицию для 8 каналов на аккаунт. |
| Ответы, правки, удаление и вложения | Проверены в двух браузерных сессиях. Править и удалять сообщение может автор. JPEG и PNG загружаются напрямую в S3 и открываются по короткоживущим ссылкам. |
| Участники, жалобы и почтовые сценарии | Проверено. Панель показывает роли и онлайн-статус. Владелец рассматривает и отклоняет жалобы. Подтверждение почты и сброс пароля прошли через Mailpit. |
| Визуальная доработка и приёмка | Далее. Доработка по макету и дизайн-системе. Затем замеры запуска, доставки и прокрутки с медиа. |

**14 ноября 2026.** Проверена production-сборка через Vite Preview в двух независимых контекстах Chrome 157. Обмен работает при обоих порядках прихода HTTP-ответа и WebSocket-события. Два сообщения с одинаковым текстом остаются отдельными записями. После разрыва пропущенные события приходят по порядку. Проверены переход к списку каналов с клавиатуры на ширине 390 px и отзыв сессии при выходе. `npm run check` и `npm run build` прошли. Начальный JavaScript — 27,2 КБ gzip. [Запуск клиента](../client/README.md).

**14 ноября 2026. Восстановление и прокрутка.** Production-сборка проверена в двух контекстах Chrome 157 на локальном API. При 313 сообщениях, включая многострочные, в DOM оставалось меньше 45 строк сообщений. Позиция при подгрузке, возврате в канал и получении 250 новых сообщений сохранялась с допуском 2 px. Если сохранённая позиция старше кэша, клиент подгружает нужные страницы. Проверены лимиты в 200 сообщений и 512 КиБ на канал, очистка при выходе и изоляция записей аккаунтов. Начальный JavaScript — 29,7 КБ gzip. Замеры FPS и задержки с медиа остаются на этапе приёмки.

**14 ноября 2026. Действия с сообщениями.** Проверены обновление цитат при правке и удалении оригинала, загрузка PNG без подписи и JPEG с подписью через SeaweedFS, удаление подписи и недоступность новой ссылки после удаления сообщения. Повтор после потери HTTP-ответа использует прежние nonce и ID вложения. Вторая сессия получает одну запись. Проверка истории и переподключения прошла повторно. Начальный JavaScript — 32,3 КБ gzip.

**14 ноября 2026. Участники, модерация и почта.** Production-сборка проверена в Chrome на локальном API с Mailpit. Панель участников доступна в том числе при ширине 390 px. При подмене ответа на `presence_available: false` клиент показал неизвестный статус. Проверены доступ владельца к списку жалоб, сохранение обоих исходов после обновления, подтверждение почты, одноразовость кода сброса и отзыв прежней сессии. После входа с новым паролем открывается исходный канал. Начальный JavaScript — 35,7 КБ gzip.
